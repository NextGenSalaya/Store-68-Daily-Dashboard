Excel จะประมวลผลในเบราว์เซอร์ ไฟล์ต้นฉบับจะไม่ถูกอัปโหลดไป GitHub

    รายชื่อไฟล์ที่ต้องใช้
      2

      ตรวจสอบก่อนเผยแพร่

      ข้อมูลบนเว็บยังไม่เปลี่ยนจนกว่าจะกดเผยแพร่

      กลุ่มข้อมูลชุดข้อมูลรายการวันที่ในรายงาน / ไฟล์

      3

      เผยแพร่ไปเว็บสาธารณะ

      เฉพาะบัญชีที่มีสิทธิ์เขียน repository นี้เท่านั้นที่เผยแพร่ได้

      ตั้งค่าสิทธิ์ GitHub ครั้งแรก
      1. เข้าสู่บัญชี GitHub ที่ดูแล NextGenSalaya/Store-68-Daily-Dashboard
      2. สร้าง Fine-grained personal access token และกำหนดวันหมดอายุ
      3. เลือก Resource owner เป็น NextGenSalaya แล้วเลือกเฉพาะ repository Store-68-Daily-Dashboard
      4. เพิ่มสิทธิ์ Contents: Read and write แล้วคัดลอกรหัสมาวางด้านล่าง

      ไม่ต้องให้สิทธิ์ผู้ดูแลระบบหรือสิทธิ์ทุก repository ดูคู่มือ GitHub

      ยังไม่มีรหัส? สร้างรหัสที่ GitHub → แล้วเลือกเฉพาะ repository Store-68-Daily-Dashboard

      ใช้ส่งข้อมูลตรงไป GitHub เท่านั้น ไม่บันทึกรหัสไว้ในเว็บหรือไฟล์ และล้างออกหลังส่งข้อมูล

      เปิด Dashboard ที่อัปเดตแล้ว →ดูสถานะบน GitHub

      ระหว่างแปลงไฟล์ให้เปิดหน้านี้ไว้ ไฟล์ขนาดใหญ่อาจใช้เวลาหลายนาที · ใช้คอมพิวเตอร์สำหรับข้อมูลทั้งชุด
